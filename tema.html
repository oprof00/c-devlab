1. Változók és memóriaterületek

Mielőtt bármilyen komplex logikát írnánk, ismernünk kell az adattípusokat. A C# erősen típusos nyelv. Az alábbi példában egy 3D játék játékosának alapvető fizikai paramétereit tároljuk el.

// Játékos entitás inicializálása a térben
string playerName = "PlayerOne";
float positionX = 14.5f;
float positionY = 0.0f;
bool isGrounded = true;

Console.WriteLine($"Entitás betöltve: {playerName}");
Console.WriteLine($"Pozíció: X:{positionX}, Y:{positionY}, Talajon: {isGrounded}");
Fordítás: Sikeres

Konzol kimenet:

Entitás betöltve: PlayerOne
Pozíció: X:14.5, Y:0, Talajon: True

2. Elágazások (If-Else) és monitorozás

Az elágazások teszik lehetővé, hogy a szoftver reagáljon a környezetére. Ebben a szimulációban egy szervergép memóriahasználatát ellenőrizzük. Ha a RAM használat kritikus szintre lép, a program riasztást küld.

int totalRamGb = 16;
int currentUsageGb = 14;

if (currentUsageGb >= totalRamGb) {
    Console.WriteLine("KRITIKUS HIBA: OutOfMemoryException veszély!");
} 
else if (currentUsageGb > 12) {
    Console.WriteLine("FIGYELMEZTETÉS: Magas memória terhelés a szerveren.");
} 
else {
    Console.WriteLine("RENDSZER: A memória használat optimális.");
}
Fordítás: Sikeres

Konzol kimenet:

FIGYELMEZTETÉS: Magas memória terhelés a szerveren.

3. Ciklusok (Foreach iteráció)

Amikor több tucat adattal dolgozunk, a ciklusok elengedhetetlenek. Itt egy Docker alapú Home Lab környezet aktív konténereit (pl. DNS szűrők, médiaszerverek) listázzuk ki egy tömbből, végigiterálva az összes elemen.

string[] activeContainers = { "CasaOS", "Jellyfin", "AdGuard Home", "Nginx" };

Console.WriteLine(">> Docker konténerek lekérdezése...");
foreach (string container in activeContainers) 
{
    Console.WriteLine($"[Online] {container}");
}
Fordítás: Sikeres

Konzol kimenet:

>> Docker konténerek lekérdezése...
[Online] CasaOS
[Online] Jellyfin
[Online] AdGuard Home
[Online] Nginx
